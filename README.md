# WebToNative

WebToNative is an Android application built using Kotlin and Jetpack Compose that allows users to browse websites inside a native Android experience.

## Features

* Google Sign-In
* Firebase Authentication
* Auto Login
* Logout
* WebView Browser
* Website History
* Room Database
* MVVM Architecture
* Featured Websites

## Tech Stack

* Kotlin
* Jetpack Compose
* Firebase Authentication
* Room Database
* Navigation Compose
* Material 3
